NOTE: nf2c members (0-3) are usually NOT in order! So look at last two HEX digits (e.g. 00, 03, 02, 01) of the MAC address

sudo /sbin/ifconfig nf2c0 10.1.0.2/24 up
sudo /sbin/ifconfig nf2c3 10.1.1.2/24 up		
sudo /sbin/ifconfig nf2c2 10.1.2.2/24 up
sudo /sbin/ifconfig nf2c1 10.1.3.2/24 up

From control network "ping" using the IP addresses you assigned above


TO USE IPERF ON THE NODES:

/usr/local/etc/emulab/emulab-iperf -c n1 -p 7001 // Set this node as a client and tell it that n1 is the server listening at port 7001
/usr/local/etc/emulab/emulab-iperf -s -p 7001   // Set this node as server and tell it to listen at port 7001
